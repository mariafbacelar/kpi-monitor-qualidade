# KPI Monitor de Qualidade

Projeto pessoal desenvolvido para estudar automação de processos,
indicadores de qualidade e análise de dados.

A ideia foi transformar um apontamento simples de produção em
monitoramento com KPI, alerta e dashboard.

## Tecnologias utilizadas
- n8n
- Node.js / Express
- Google Forms
- Google Sheets
- Looker Studio

## Funcionamento geral
1. Registro da produção via formulário
2. Orquestração dos dados no n8n
3. Cálculo dos KPIs via API
4. Visualização em dashboard
5. Envio de alerta automático por e-mail

Projeto em desenvolvimento, com foco em aprendizado.
